# EcoVerse 🌍🎮  
*A futuristic game on sustainability — adventure, learning, and real-world impact*

## 📌 Overview
**EcoVerse** is a Unity-based game developed as part of the Game Development course at **TU Ilmenau**.  
It combines **adventure gameplay**, **quiz challenges**, and **knowledge pop-ups** to raise awareness about sustainability and climate change.  

Players step into the shoes of **Astrobolt**, an astronaut who accidentally dumps Earth’s garbage on Planet X.  
To return home, he must collect renewable energy sources while learning about sustainable practices.  

---

## 🎯 Objectives
- Educate players about **sustainability and renewable energy**.  
- Create an engaging mix of **exploration, quizzes, and reflex challenges**.  
- Showcase how games can be used as **tools for education and awareness**.  

---

## 🛠️ Tech Stack
- **Unity (2022 LTS)**  
- **C# scripting**  
- **Blender** for character and environment assets  
- **Audacity & Adobe Audition** for sound design  

---

## 🎮 Gameplay Features
- **Multi-genre experience**: Adventure + Reflex + Quiz.  
- **Knowledge Pop-ups**: Learn sustainability facts during play.  
- **Quiz Levels**: Answer questions to earn shields and protection.  
- **Day-Night Cycles**: Dynamic environment visuals.  
- **Voice + Keyboard Controls**.  
- **Sustainable Energy Assets**: Solar, Wind, etc.  
- **Final Realization**: Astrobolt learns — *dumping garbage elsewhere is never the solution*.  

---

## 📊 Results
- Successfully developed a **90+ minute playable game** with multiple levels.  
- Demonstrated how **serious games** can raise awareness on global issues.  
- Presented at TU Ilmenau Game Exhibition (2024).
